# Model Checkpoint

This directory is reserved for trained model checkpoints.

The final model used in this project is **EfficientNet-B0**, pretrained on ImageNet and fine-tuned on the Stanford Cars dataset for 196-class car classification.

## Best Model

The best checkpoint was selected according to validation accuracy.

- Best epoch: **18**
- Training accuracy: **97.54%**
- Validation accuracy: **78.51%**
- Test accuracy: **78.52%**
- Macro Precision: **79.33%**
- Macro Recall: **78.48%**
- Macro F1-Score: **78.50%**

The checkpoint generated by the notebook is:

`efficientnet_b0_stanford_cars_best.pth`

The trained `.pth` file is not stored directly in this repository. It can be reproduced by running the training notebook located at:

`notebooks/Stanford_Cars_EfficientNetB0.ipynb`
